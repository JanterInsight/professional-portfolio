# NexusAI

Asistente de inteligencia artificial para maximizar la productividad y organizar tu día.

## Características

- **Organización Inteligente**: Clasifica automáticamente tus tareas y priorízalas según tu estilo de vida
- **Respuestas Instantáneas**: Obtén respuestas precisas y útiles en milisegundos
- **Análisis de Productividad**: Visualiza tu progreso con gráficos detallados
- **Privacidad Total**: Tus datos están protegidos con encriptación de última generación

## Tecnologías

- HTML5
- CSS3 (diseño responsive)
- JavaScript (ES6+)

## Estructura del Proyecto

```
nexusai/

├── styles.css      # Estilos CSS
├── scripts.js      # Funcionalidad JavaScript

```
